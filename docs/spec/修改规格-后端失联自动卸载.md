# rclone 后端失联自动卸载挂载点 — 规格文档

## 1. 概述

### 1.1 目标

在 rclone 用 mount 命令挂载远程后端（如 WebDAV）后，如果后端因网络中断、服务端宕机等原因彻底失联，且所有 API 重试均已耗尽时，**自动卸载本地挂载点**，避免以下问题：

- **Windows**：虚拟盘符粘滞、Explorer 卡死、用户只能重启
- **Linux/macOS**：访问挂载点的进程卡死（D 状态）、`fusermount -uz` 才能恢复
- **用户无感知**：不知道后端已断连，无处下手

### 1.2 修改范围

- `lib/pacer/pacer.go` — pacer 底层新增重试耗尽回调机制
- `lib/pacer/onmaxretries.go` — **新文件**，回调的公开 API
- `fs/pacer_ext.go` — **新文件**，透传 SetOnMaxRetries 到 fs.Pacer
- `backend/webdav/webdav_ext.go` — **新文件**，WebDAV 暴露 pacer
- `cmd/mountlib/autounmount.go` — **新文件**，自动卸载统一入口
- `cmd/mountlib/mount.go` — 挂载时注册自动卸载（1 行）

## 2. 新增文件

### 2.1 `lib/pacer/onmaxretries.go`

**路径**: `lib/pacer/onmaxretries.go`

**用途**: 在 pacer 层新增"重试耗尽"回调机制。

**API**:

```go
// OnMaxRetriesOption 设置回调，当所有重试耗尽时调用，传入最后的错误。
func OnMaxRetriesOption(f func(err error)) Option

// SetOnMaxRetries 设置重试耗尽回调（可在 pacer 创建后随时设置）。
func (p *Pacer) SetOnMaxRetries(f func(err error))
```

**触发条件**: `pacer.call()` 中循环正常结束且 `retry == true`，表示所有重试均已尝试但仍需重试（后端连续失败）。

### 2.2 `fs/pacer_ext.go`

**路径**: `fs/pacer_ext.go`

**用途**: 将 `SetOnMaxRetries` 透传到 `fs.Pacer` 层。

**API**:

```go
func (p *Pacer) SetOnMaxRetries(f func(err error))
```

### 2.3 `backend/webdav/webdav_ext.go`

**路径**: `backend/webdav/webdav_ext.go`

**用途**: WebDAV 后端暴露内部 pacer 给 mount 层监控。

**API**:

```go
func (f *Fs) GetPacer() *fs.Pacer
```

### 2.4 `cmd/mountlib/autounmount.go`

**路径**: `cmd/mountlib/autounmount.go`

**用途**: 挂载层的自动卸载统一入口。

**定义**:

```go
// PacerProvider 是后端可选的接口，用于暴露 pacer 给 mount 层。
type PacerProvider interface {
    GetPacer() *fs.Pacer
}

// AutoUnmountOnFailure 在后端的 pacer 上注册重试耗尽回调。
// 当所有 API 重试耗尽时自动调用 unmountFn 卸载挂载点。
func AutoUnmountOnFailure(f fs.Fs, unmountFn func() error)
```

**安全措施**:
- `sync.Once`：防止并发重试耗尽时多次触发卸载
- 非 `PacerProvider` 后端静默跳过，不影响原有行为
- 卸载失败仅记录日志，不 panic

## 3. 修改文件

### 3.1 `lib/pacer/pacer.go`

#### a) `pacerOptions` 结构体新增字段

```go
onMaxRetries   func(err error)    // 🏢 悦库修改: 重试耗尽时的回调，用于触发自动卸载
```

#### b) `call()` 方法末尾新增回调调用

```go
// 🏢 悦库修改: 重试全部耗尽后通知上层（如 mount 层）触发自动卸载
if retry && p.onMaxRetries != nil {
    p.onMaxRetries(err)
}
```

**关键逻辑**: 循环正常结束（未 `break`）且 `retry` 仍为 `true` → 所有重试均耗尽，调用回调传入最终错误。

### 3.2 `cmd/mountlib/mount.go`

在 `MountPoint.Mount()` 方法中，`MountFn` 返回后、`UnmountFn` 已就绪时，加一行：

```go
AutoUnmountOnFailure(m.Fs, m.UnmountFn) // 🏢 悦库修改: 注册重试耗尽自动卸载
```

位置位于 `MountFn` 调用之后、`m.MountedOn` 赋值之前，此时文件系统已挂载且 unmount 函数可用。

## 4. 用户可见效果

### 4.1 正常情况

```bash
rclone mount webdav: X: --vfs-cache-mode full
# 挂载成功，X: 盘可用，后台注册自动卸载
```

```
2026/07/08 10:00:00 DEBUG : webdav root '': Auto-unmount on connection failure enabled
```

### 4.2 后端断连时

```
2026/07/08 10:05:00 ERROR : webdav root '': Remote unreachable after all retries, unmounting: connection refused
2026/07/08 10:05:00 DEBUG : Calling host.Unmount
2026/07/08 10:05:00 DEBUG : Unmounted successfully
```

### 4.3 不支持的远端

```
2026/07/08 10:00:00 DEBUG : local: Auto-unmount on failure not supported by this backend
```

仅 DEBUG 日志，不影响使用。

### 4.4 触发后恢复

如果后端只是短暂抖动，重试耗尽前连接恢复，则不会触发自动卸载。阈值由 `--low-level-retries` 和 pacer 退避算法决定。

## 5. 扩展

### 5.1 为其他后端添加支持

任何有 `*fs.Pacer` 字段的后端，只需添加一个文件 + 一个方法：

```go
// backend/s3/s3_ext.go
package s3

import "github.com/rclone/rclone/fs"

func (f *Fs) GetPacer() *fs.Pacer { return f.c.pacer }
```

无需修改 mount 层代码，自动生效。

### 5.2 后端适配清单

| 后端 | 字段路径 | GetPacer 即可 |
|------|---------|--------------|
| WebDAV | `f.pacer` | ✅ 已添加 |
| S3 | `f.c.pacer` | ✅ |
| Google Drive | `f.srv.pacer` | ✅ |
| Dropbox | `f.pacer` | ✅ |
| OneDrive | `f.srv.pacer` | ✅ |
| SFTP | `f.pacer` | ✅ |
| local | 无 pacer | 不适用 |

## 6. 配置

无新增配置项。自动卸载默认启用（前提是后端支持），不可关闭——后端不可达时卸载挂载点是保护行为，没有理由让用户选择不保护。

如果用户觉得触发太敏感，可调低 `--low-level-retries`（默认 3）来减少等待时间。

---

## 7. 依赖

无新增外部依赖。仅使用 Go 标准库 `sync`。

## 8. 回归影响

### 8.1 兼容性

| 场景 | 行为 |
|------|------|
| 无 cgo 的 Windows 构建 | 不受影响（自动卸载代码在内核中，但 `mount` 命令本身不可用） |
| 非 mount 命令（sync/copy/ls） | 不受影响（`AutoUnmountOnFailure` 只从 `Mount()` 调用） |
| 不支持 `PacerProvider` 的后端 | 不受影响（静默跳过） |
| 网络短暂抖动后恢复 | 不受影响（重试耗尽前已恢复，不触发回调） |

### 8.2 构建变化

- `lib/pacer` 包无新增依赖
- `cmd/mountlib` 包无新增依赖
- `backend/webdav` 包无新增依赖
- `fs` 包无新增依赖
